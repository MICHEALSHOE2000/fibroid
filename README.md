A mobile-first educational website for fibroid awareness and Utero Clear product enquiries.

## What is included

- Fibroid symptoms and common types
- Diagnosis-first care pathway
- Real Utero Clear product photography
- Transparent label and pack details
- Medical red-flag guidance and FAQ
- Responsive desktop and mobile design
- Search metadata and ad-friendly responsible copy

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
